# Counter: every screen

What the counter program tells the cashier, a manager and the owner
(`docs/SCREEN-RULES.md`). The list is made from the code; do not edit it
by hand. To write it again, run the test
`sc_12_the_list_on_disk_is_current` of `openbmt-counter-node` with
`OPENBMT_WRITE_SCREENS=1`.
