# The counter call protocol

Generated by a test of `openbmt-counter-ffi` from the tables its
encoder uses (`cargo test -p openbmt-counter-ffi protocol`); the test
fails when this file differs. Do not edit it by hand.

One function, `dispatch`, takes a request and returns a response.

```text
request   "OBMm" | version 1 | op u16 | handle u64 | fields...
response  "OBMn" | version 1 | status u8 | ...
  status 0  ok: the result of the op
  status 1  refused   then rule, text and words
  status 2  store     then rule, text and words
  status 3  state     then rule, text and words
  status 4  internal  then rule, text and words
  rule and text are each a u16 length and UTF-8
  words: tone u8 | who u8 | heading | what | next
    | code (flag, string) | at (flag, u64)
    | quoted (flag, from, text) | detail (flag, string)
    every string is a u16 length and UTF-8
```

Integers are little-endian. A bool is one byte, 0 or 1. A string is a
u32 length and UTF-8 (a `str16` is a u16 length and UTF-8, and is
used only inside `Words`). `list<T>` is a u32 count and the
elements; `list<u8>` is the bytes type. `option<T>` is a flag byte 0
or 1 and then the value. An enum is a tag byte and then the fields of
its variant. A record is its fields in the order given. A request is
at most 1048576 bytes, is read completely before anything is done,
and is refused when bytes are left over.

Times are seconds since 1970. Money is in minor units of the shop's
currency or in satoshis, as the field says. The QR modules of a
`Payment` are `qr_size` squared bits, dark as 1, in one stream most
significant bit first, row by row, the last byte padded with 0.

## Words

The words say what a person is shown, for an error and for every
state a result carries. The numbers of the tone and of the person who
does the next step are:

```text
tone: Info=0 Good=1 Stop=2 Ended=3
who:  Nobody=0 Customer=1 Cashier=2 Manager=3 Owner=4 KeyHolder=5 BoxKeeper=6
```

The time `at` is in seconds since 1970, for the app to show on the
person's own clock. `quoted` is text from another device, with where it
came from. `detail` is for the small print.

## Ops

The handle names the node the op works on: `zero` (the field is 0) or
`node` (from `start`). `pump` may run on one thread while the other
ops run on another; it waits for at most 250 ms.
