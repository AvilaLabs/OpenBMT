    The demo could not start in this browser. It needs WebAssembly, which current versions of every major browser have.

    What is real here

    The screens, the checks and the words are the apps' own, from the same code that runs on the tablet and the phone.

    The blockchain, the customer's wallet and the price of bitcoin are pretend. The addresses are for a test network, so no wallet can send real bitcoin to them.

    OpenBMT is open source and not released yet. No independent security audit has been done. Read the handbook for how it works and what it will never do.
